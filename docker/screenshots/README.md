# Screenshots checklist

Capture and save the following screenshots in this folder after starting the application:

- [ ] `01-homepage.png` — homepage, including the empty state or a list of stories.
- [ ] `02-create-post.png` — the create form with a title and content filled in.
- [ ] `03-post-detail.png` — a saved story with its Edit and Delete actions.
- [ ] `04-compose-services.png` — terminal output from `docker compose ps` showing the web and database services as healthy/running.

Use a browser screenshot tool or your operating system's screenshot shortcut. Do not include passwords, `.env` contents, or other secrets in screenshots.
